# Output Format

## If questions are needed

1. Brief intake summary
2. Final prompt block

## If no questions are needed

- Output only the final prompt block

## Prompt requirements

- Chinese by default
- Copy-pasteable as one block
- Includes concrete values for all placeholders
- Includes inferred brand cues
- Ends with negative constraints

## Tone

- Direct
- Practical
- No analysis dump
- No long explanation
