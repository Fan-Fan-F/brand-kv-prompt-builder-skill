# Intake Rules

## Ask only what is missing

- Main product, if the user wants a specific hero product
- Target audience
- Aspect ratio
- KV type
- Platform use
- Slogan, if the user wants to provide one

## Ask limit

- Prefer 0 to 3 questions
- Ask at most 5 questions total
- If the brand is familiar, infer missing details
- If the brand is unclear, ask one clarifying question first

## Natural question examples

- 你想指定主推产品吗？
- 这张图主要发到哪里？
- 你更想要哪种 KV：产品英雄、情绪氛围、强口号，还是人物场景？
- 要我顺手把广告语也一起想了吗？
